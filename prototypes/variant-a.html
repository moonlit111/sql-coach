第 7 题 Level 3 · 难点 EXISTS / NOT EXISTS 相关子查询

查询所有曾下过订单的用户姓名

数据库中有 users 与 orders 两张表。请使用相关子查询配合 EXISTS 子句，找出所有曾经在 orders 表中出现过的 user。要求：不要使用 IN 与 JOIN 写法。

· · ·

你的解答

SELECT u.name FROM users u WHERE EXISTS ( SELECT 1 FROM orders o WHERE o.user_id = u.id );
Verdict 回答正确 — 你的解返回了 3 行，与参考答案在多重集语义下完全一致。

查询结果（3 行）

name
Alice
Bob
Charlie

错题问答 · 与 Tutor 的对话

漂亮——这就是 EXISTS 的标准模式。注意到 SELECT 1 而不是 SELECT * 了吗？这是个老派习惯，因为 EXISTS 只在乎"有没有"，不在乎"是什么"。
为什么这种场景不能用 IN？
可以——但 EXISTS 在 orders 表特别大、且 user_id 上有索引时通常更快，因为它一旦找到一行就短路返回。IN 则需要先扫完整个子查询。
